# moji-data

文字コマ対戦ゲーム（Roblox）用の文字データ置き場です。
フォントから計算した「文字の形・当たり判定・ステータス」を置いておき、ゲームがここから必要な文字を取りに来ます。

## 中身

- `index.json` … 版番号と、字体ごとに入っているブロックの一覧
- `g/<字体>/<ブロック>.json` … 64文字ずつのデータ（ブロック = コードポイント ÷ 64 を16進数4桁）
  - キーは文字のコードポイント（16進）
  - 書き方の詳しい説明は `tools/export.py` の先頭にあります（版2：座標は 1/100 スタッドの整数）
- `tools/` … データを作るプログラム（`factory.py` が文字工場、`export.py` が書き出し）

## 字体

| 名前 | 内容 |
|---|---|
| gothic | ゴシック |
| mincho | 明朝 |
| pop | 丸っこい太字 |
| pixel | ドット字（GNU Unifont） |
| outline | ふちだけ（black の中を空洞にする） |
| italic | 斜め（gothic を傾ける） |

※ 今入っているのは試作用のフォントで作った約15万文字です（フォントは仮のもの）。
