# moji-data

文字コマ対戦ゲーム（Roblox）用の文字データ置き場です。
フォントから計算した「文字の形・当たり判定・ステータス」を置いておき、ゲームがここから必要な文字を取りに来ます。

## 中身

- `index.json` … 版番号と、字体ごとに入っているブロックの一覧
- `g/<字体>/<ブロック>.json` … 64文字ずつのデータ（ブロック = コードポイント ÷ 64 を16進数4桁）
  - キーは文字のコードポイント（16進）
  - `a` 面積 / `m` 重心から一番遠い点まで / `b` バランス / `k` タイプ（P=POWER, S=SPEED, B=BALANCE, C=CRITICAL）
  - `v` 輪郭の頂点 / `t` 上面の三角形 / `r`・`rl` 輪郭の並び / `x` 当たり判定の長方形 / `p` 尖った先端
  - 単位はスタッド、原点は重心、z は文字の下向き
- `tools/` … データを作るプログラム（`factory.py` が文字工場、`export.py` が書き出し）

## 字体

| 名前 | 内容 |
|---|---|
| gothic | ゴシック |
| mincho | 明朝 |
| pop | 丸っこい太字 |

※ 今入っているのは試作用のデータです（フォントは仮のもの）。
